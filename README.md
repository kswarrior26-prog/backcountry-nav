# Backcountry Nav

Off-road map app for phones: USGS topo and imagery, geologic map overlay, FAA VFR/IFR aeronautical charts, NOAA radar and NWS forecasts, live GPS speed and altitude, compass, track recording, waypoints with GPX import/export, and offline map saving.

Open it at **https://kswarrior26-prog.github.io/backcountry-nav/** and allow location when asked.
